# legal-corpus

Минимальный локальный инструмент для установки и проверки корпуса российского законодательства.

Текущая версия инструмента подготовлена как MVP `0.1.0`.

Related skill: [legal-analysis-rf-sources](https://github.com/serenedos/legal-analysis-rf-sources) — skill that can use this corpus as optional local layer C.

## Текущий MVP

Версия инструмента: `0.1.0`.

MVP умеет устанавливать профиль из источника A, загружать отдельный документ из источника A и устанавливать уже подготовленный локальный снимок корпуса, если его путь передан явно. Установка и обновление не удаляют существующие файлы. Инструмент не содержит путей конкретного разработчика.

Профиль `min` включает четыре части ГК РФ, АПК РФ и ГПК РФ. Профиль `max` включает все документы, присутствующие в текущем каталоге MVP.

## Запуск

Из этой папки:

```text
python legal_corpus.py status
python legal_corpus.py list
python legal_corpus.py install min
python legal_corpus.py install max --dry-run
python legal_corpus.py fetch gk1
python legal_corpus.py setup
```

При обычном `install` документы загружаются из источника A. Уже установленная актуальная редакция пропускается; отсутствующие документы добавляются. Для локального подготовленного снимка можно явно передать источник:

```text
python legal_corpus.py --source C:\path\to\source-corpus install min
```

Для первого запуска используйте `setup`: он устанавливает профиль `min` в стандартное пользовательское хранилище Windows. Профиль можно расширить до `max`.

```text
python legal_corpus.py setup
python legal_corpus.py setup --profile max
```

По умолчанию используется стандартное пользовательское хранилище:

```text
Windows: %LOCALAPPDATA%\legal-corpus
macOS:   ~/Library/Application Support/legal-corpus
Linux:   $XDG_DATA_HOME/legal-corpus или ~/.local/share/legal-corpus
```

Путь можно переопределить переменной `LEGAL_CORPUS_HOME` или параметром `--root`:

```text
python legal_corpus.py --root C:\path\to\corpus install min
```

Автоматическое обнаружение произвольных пользовательских каталогов пока не реализовано. Опытный пользователь может временно задать `LEGAL_CORPUS_HOME` или вручную указать `--root`; автоматическая настройка будет добавлена позже.

Источник локального снимка задаётся параметром `--source` или переменной `LEGAL_CORPUS_SOURCE`. Без одного из этих параметров локальная установка завершается с понятной ошибкой; это предотвращает зависимость от чужого компьютера.

Команда `fetch` загружает один документ из источника A. Например, `fetch gk1` сохраняет актуальную редакцию ГК РФ, части первой, и обновляет `MANIFEST.json`. Предыдущие редакции не удаляются.

## Принцип идентификации

Каждый документ получает короткий устойчивый ID. Для частей ГК используются `gk1`, `gk2`, `gk3`, `gk4`; для кодексов — `apk`, `gpk`, `sk`, `zk`, `grk`, `upk`, `koap`. Юридическое название, редакция, даты, ссылки на источники и контрольные суммы берутся из исходного `MANIFEST.json` и сохраняются в установленном манифесте.

## Ограничения MVP

- сетевой `fetch` пока настроен только для документов, у которых в каталоге описаны параметры источника A;
- `min` и `max` используют каталог документов, описанный в `catalog.json`;
- поиск по тематике и выбор между несколькими одноимёнными законами пока не реализованы;
- корпус предназначен для навигации и анализа источников, а не заменяет проверку действующей редакции по официальному источнику.
